# 大厂5年被裁经历，最终拿到N+3

## 背景

我在某大厂工作了整整5年，从一个初级工程师做到了高级工程师。2026年3月的一个周一早上，我的直属领导突然把我叫到会议室，告诉我部门要优化，我的岗位受到影响。

## 第一次谈判

HR给的方案是N，也就是5个月工资。我当时很震惊，但还是保持了冷静。我说：

> "我需要时间看一下协议，明天给你答复。"

**重点提醒：不要当场签字！**

## 我做了什么

回家后我做了以下几件事：

1. **仔细阅读协议**：发现协议中有一些不利条款
2. **计算法定赔偿**：根据我的工龄和月薪，法定标准应该是N+1
3. **咨询律师朋友**：确认了自己的权益
4. **整理证据**：保存了所有工作邮件、绩效评估、项目成果

## 第二次谈判

第二天我回去跟HR谈：

- 指出协议中的不合理条款
- 提出N+1是法定最低标准
- 表示希望公司考虑我5年的贡献
- 暗示如果协商不成，我了解劳动仲裁流程

## 最终结果

经过3轮谈判，最终拿到了**N+3**的方案：

| 项目 | 金额 |
|------|------|
| 经济补偿金（5N） | ¥150,000 |
| 代通知金（+1） | ¥30,000 |
| 额外补偿（+2） | ¥60,000 |
| 未休年假 | ¥8,276 |
| **合计** | **¥248,276** |

## 经验总结

1. **保持冷静**，不要情绪化
2. **不要当场签字**，给自己争取时间
3. **了解法律**，知道自己的底线
4. **保留证据**，这是谈判的筹码
5. **态度坚定但友善**，不要撕破脸

希望我的经历能帮到大家。记住，裁员不是你的错，保护好自己的权益最重要。
