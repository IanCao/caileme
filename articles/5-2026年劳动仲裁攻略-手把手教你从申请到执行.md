# 2026年劳动仲裁攻略：手把手教你从申请到执行

> 2026年劳动仲裁案件增长超40%，但90%的人不知道这些技巧

## 为什么要仲裁

根据最新数据，2026年全国劳动仲裁案件数量持续增长，越来越多的劳动者选择用法律武器维护自己的权益。

**劳动仲裁是免费的**，而且是劳动争议诉讼的前置程序。不满意仲裁结果，还可以向法院起诉。

## 什么情况下可以仲裁

只要公司侵犯了你的劳动权益，就可以申请仲裁：

| 常见争议类型 | 示例 |
|-------------|------|
| 工资争议 | 拖欠工资、加班费、年终奖 |
| 社保公积金 | 不缴社保、基数不对 |
| 劳动合同 | 违法解除、拒绝续签 |
| 经济补偿 | N+1、2N赔偿没给 |
| 其他 | 违法调岗、违法降薪 |

## 2026年仲裁新变化

### 1. 新就业形态劳动者权益保障

2026年1月27日，人社部发布《新就业形态劳动者基本权益保障办法》，明确表示：

> "平台企业应与劳动者签订书面协议，明确劳动报酬、支付周期、算法规则等核心事项。"

如果你在平台工作（如外卖、网约车），这个政策对你很重要。

### 2. 司法解释更细化

2025年9月1日施行的《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》，进一步细化了规则：

- 明确加班费的举证责任
- 细化违法解除的赔偿标准
- 增加了劳动者胜诉的可能

## 仲裁全流程

### 第一步：准备材料

**必须准备**：
1. 身份证原件及复印件
2. 仲裁申请书
3. 证据清单及证据材料

**证据准备建议**：
| 证据类型 | 重要性 |
|---------|--------|
| 劳动合同 | ⭐⭐⭐⭐⭐ |
| 工资流水 | ⭐⭐⭐⭐⭐ |
| 考勤记录 | ⭐⭐⭐⭐ |
| 聊天记录/录音 | ⭐⭐⭐⭐⭐ |
| 公司的书面通知 | ⭐⭐⭐⭐⭐ |

### 第二步：提交申请

**受理部门**：当地劳动人事争议仲裁委员会
- 各区人社局都有
- 可以电话咨询或网上预约

**受理时间**：一般5个工作日内
**受理费用**：**免费！**

### 第三步：等待开庭

- 受理后45天内安排开庭
- 复杂案件可延长15天
- 开庭前会提前通知双方

### 第四步：开庭

**开庭流程**：
1. 申请人陈述诉求
2. 被申请人答辩
3. 双方举证质证
4. 仲裁员调查
5. 最后陈述
6. 调解 or 裁决

### 第五步：领取裁决

- 裁决书15天内送达双方
- 任何一方不服，可在15天内向法院起诉
- 如果不起诉，裁决书生效

### 第六步：强制执行

如果公司不执行裁决：

1. 准备材料：仲裁裁决书、执行申请书、身份证复印件
2. 申请执行：前往基层人民法院
3. 执行结果：查封公司账户、冻结资产、列入失信名单

## 实用技巧

### 1. 时效问题

> **注意**：劳动仲裁时效一般为**1年**！

从知道权益被侵害之日起计算，不要拖。

### 2. 管辖选择

- 公司所在地仲裁委员会
- 合同履行地仲裁委员会
- 哪个近选哪个

### 3. 证据技巧

- 聊天记录要完整，不要只截图
- 录音要保存原始文件
- 尽可能多准备，防止遗漏

### 4. 调解优先

仲裁前可以先申请调解，很多案件在调解阶段就解决了，省时省力！

## 常见问题

**Q：没签合同能仲裁吗？**
A：可以！事实劳动关系同样受法律保护。

**Q：仲裁期间还能找工作吗？**
A：当然可以！不影响你找新工作。

**Q：仲裁会不会被公司报复？**
A：法律禁止打击报复，违法的公司会更被动。
